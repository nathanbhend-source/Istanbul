 Welcome to Istanbul – Travel Guide Website

A simple, elegant travel webpage dedicated to the beautiful city of Istanbul, Turkey. This project showcases the city’s charm, culture, and popular cafes, complete with maps, images, and travel information — all designed in a clean and modern layout.

Features

Introduction to Istanbul with key facts
 A list of favorite cafes with descriptions, photos, and Google Maps embeds
A photo gallery of Istanbul
 Useful links like maps, public transport info, and airport website
 “About Me” and “About this website” sections
 Responsive layout and elegant design using modern HTML and CSS
